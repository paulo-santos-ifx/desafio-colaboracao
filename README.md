# Desafio Markdown e colaboração

Este repositório é um pequeno desafio criado para demonstrar as capacidades do **Markdown** no GitHub.

---

## Objetivo

Explorar diferentes elementos do Markdown, incluindo:

- Títulos
- Listas
- Tabelas
- Código
- Links
- Imagens
- Citações
- Checklists

## Formatação de Texto e tabelas

| Estilo        | Exemplo              |
|--------------|---------------------|
| Negrito       | **Texto**           |
| Itálico       | *Texto*             |
| Riscado       | ~~Texto~~           |
| Código        | `console.log()`     |
| Citação       | > Texto citado      |
